# Basic HTML Website

This project demonstrates how to **structure a multi-page website using only HTML** — no CSS or styling.  
It teaches HTML semantics, layout planning, and SEO fundamentals.

---

## 📄 Pages

- **index.html** – Homepage with projects, experience, and education
- **projects.html** – List of HTML projects
- **articles.html** – Sample articles/blogs
- **contact.html** – Contact form

---

## 🧱 Project Goals

- Create multiple interlinked HTML pages
- Add semantic HTML layout (header, nav, main, footer)
- Include SEO and OG meta tags
- Build a basic contact form (name, email, message)
- Prepare for future styling with CSS

---

## ⚙️ How to Run

Open `index.html` directly in a browser  
or use a local server for better experience (e.g., Live Server extension in VSCode).
