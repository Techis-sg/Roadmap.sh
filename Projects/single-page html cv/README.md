# Single-Page HTML CV

This project is a **single-page CV (Curriculum Vitae)** built entirely using **semantic HTML**.  
It serves as a foundation for learning how to structure a professional CV webpage before adding any CSS styling.

---

## 🧠 Project Overview

The goal of this project is to:
- Practice **semantic HTML**.
- Include **SEO** and **Open Graph (OG)** meta tags.
- Link a **favicon**.
- Prepare the structure for future styling using CSS.

Your CV includes:
- **Header** with your name, role, and contact details.
- **Skills**, **Education**, and **Experience** sections.
- **Links** to online profiles (e.g., LinkedIn, GitHub).
- A **Footer** for ownership or copyright.

---

## ⚙️ How to Run This Project

You can run this project locally in two ways:

### Option 1 — Open Directly
1. Locate the `index.html` file in your project folder.
2. Double-click the file or right-click → **Open with → Browser (e.g., Chrome, Edge, Firefox)**.


### Option 2 — use any online html viewer tools like codepen
1. Put this code in html viewer like codepen or w3schools html editor and see live.
